# 力扣讨论 · 文章目录

为 `leetcode.cn/discuss/post/…` 文章提供浮动目录的 Tampermonkey（油猴）脚本。

## 安装使用

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开扩展管理面板，选择「添加新脚本」。
3. 用本项目 `leetcode-discuss-toc.user.js` 的完整内容替换编辑器里的默认内容，保存。
4. 刷新力扣讨论文章。右侧默认显示一列章节小方块，鼠标悬停后展开目录，移出后自动收缩。

更新已有脚本时，在油猴管理面板编辑原脚本，替换为新版完整内容、保存，再刷新力扣页面。当前版本为 1.0.11。

如果浏览器提示需要允许扩展执行用户脚本，按 Tampermonkey 的提示启用相应权限。

日常使用不需要 Node.js、构建步骤、外部脚本或网络接口。脚本只读取当前页面的文章标题；
每次打开文章默认显示方块预览，多级章节保持展开。`@grant window.onurlchange` 用于感知站内文章切换。

## 功能

- 保持原来的右侧定位和顶部导航避让；未悬停时显示浅灰色章节方块，悬停后目录从右侧向页面中间平滑滑入，移出约 140ms 后开始滑回，过渡约 320ms。
- 方块与面板交替淡入淡出，快速移回从当前位置反向过渡，不重新闪现；遵循系统「减少动态效果」偏好。
- 方块逐一对应一级目录项，数量不包含子标题；阅读子章节时，橙色标记其所属一级目录的方块。长目录的方块列在可用高度内滚动，并保持当前标记可见。
- 悬停展开不抢正文焦点，搜索词和章节折叠状态在收起后保留。键盘聚焦方块可打开目录，触屏也可点击打开。
- 收集文章正文中的 `h1` 到 `h6`，保持原始顺序，支持跳级标题、同名标题与缺失锚点。
- 多级目录可单独折叠；一个总开关切换全部展开/收起，图标显示当前状态。
- 搜索框与展开/收起总开关同排显示，搜索框自适应剩余宽度。
- 不显示章节总数、匹配数量等统计信息。
- 目录始终避开当前可见的站点顶部导航栏；滚回页首和调整窗口大小时自动更新位置和可用高度。
- 搜索标题时保留祖先路径；清空搜索恢复原来的折叠状态。
- 点击标题平滑定位，给固定导航留出间距，遵循系统「减少动态效果」偏好。
- 网页滚动时按当前小节内的阅读进度连续移动目录，并用逐帧动画平滑跟随，跨章节时延续当前滚动位置。
- 保留全部或部分展开/收起状态：当前小节隐藏时，跟随并高亮最近的可见上级；展开后恢复到当前小节。
- 面板收起时，隐藏的完整目录也会随正文同步到当前章节；悬停前完成最新位置更新，滑入时只播放横向过渡，不再纵向追赶。搜索期间不移动搜索结果，清空搜索后恢复跟随。
- 手动浏览目录、展开/收起单节或全部章节时保留浏览位置，只更新高亮；正文再次滚动时恢复平滑跟随。
- 自动适应异步加载、标题增删改，以及站内无刷新切换文章；离开文章页时移除目录。
- 支持深浅色、窄屏和键盘操作；通过鼠标移出或键盘焦点离开自动收起。
- 使用 Shadow DOM 隔离目录样式；不收集评论中的标题。

## 本地开发和验证

需要 Node.js 20 或更高版本：

```sh
npm ci
npm run check
npm test
npm run demo
```

打开终端输出的演示地址（默认 `http://127.0.0.1:4173/discuss/post/1001/demo/`）。
右侧面板加载的是实际用户脚本。点击「演示平滑跟随」可观察正文和目录同时滚动。
页面还可切换文章、异步追加章节和切换主题，评论中包含一个用于验证正文隔离的干扰标题。
端口被占用时可用 `PORT=4174 npm run demo`。

```text
leetcode-discuss-toc.user.js  可直接安装的脚本，也是源文件
tests/userscript.test.mjs    DOM 交互与生命周期回归测试
demo/                       本地长文章演示
scripts/serve-demo.mjs       仅监听 127.0.0.1 的演示服务器
```

测试使用 jsdom，覆盖正文隔离、完整标题层级、重复标题、跳转参数、搜索折叠、长章节高亮、
异步加载、文章切换、重复注入、样式恢复和主题等。jsdom 不执行真实浏览器布局；视觉布局和平滑滚动需要浏览器验证。

当前 87 项回归测试全部通过，包括移出自动收起、移除关闭入口、按键不被拦截、隐藏目录后台同步、刚滚动就悬停、滑入期间纵向位置稳定、动画期间的交互权限和焦点、快速重入、一级目录方块数量、子章节归属、顶部导航避让、手动折叠保留位置、搜索和避免正文跳动等场景。

## 页面适配

主要正文选择器为 `#main-content [class*="Body_markdown__"]`。
2026-10-21 在数据结构题单和链表/二叉树/回溯题单的实际 DOM 中检查过此结构。
`ARTICLE_SELECTORS` 中保留了备用规则；如果力扣重构正文容器，可在这里调整。
备用规则按正文出现顺序选择第一个匹配容器，不按评论标题数评分。

脚本在力扣站点加载，以覆盖从其他页面无刷新进入文章的情况，但仅在 `/discuss/post/<数字>/…` 路径挂载。
原有标题 `id` 不会被覆盖，跳转直接使用 DOM 元素引用，也不修改 URL hash 或增加浏览历史。
正文变更通过防抖后的 MutationObserver 处理；普通评论、代码块更新不重建目录。
Tampermonkey 不提供 `urlchange` 时，兼容分支每 800ms 只比较一次 URL 路径。
